
🚗 UK Accident Trends Casualty Analysis

Author: Muhammad Suleman

📌 Project Description

This project analyzes UK road accident data (2005–2014) to uncover patterns in accident trends, casualty distribution, dangerous regions, road conditions, and accident severity.

The analysis leverages interactive visualizations and geospatial techniques to extract meaningful insights from 1.5+ million accident records.

🧠 Project Overview

The project focuses on:

Accident frequency trends over time
Casualty distribution patterns
Regional accident analysis
Highway authority risk evaluation
Road type and network analysis
Environmental impact on accidents
Urban vs rural comparison
Accident severity distribution
